# Android 本地客户端改造

本 fork 保留上游 Apache-2.0 许可证。Android 优先，不是 OpenAI 官方客户端。

## 功能与边界

- 原生 `values`、`values-zh`、`values-ja` 字符串；侧栏 → 设置 → 显示语言提供跟随系统、中文、English、日本語，切换立即生效并停留在设置页，重启保留选择。Android 13 以上与系统的应用语言选择同步，旧系统由客户端保存选择。
- 聊天：手机直接连接 HTTPS OpenAI 兼容接口，支持 Chat Completions 和 Responses 流式回复、自定义模型 ID、模型拉取和推理参数。
- 日常对话运行时可切换模型、推理强度及供应商；当前请求使用开始时的配置，后续发送、排队消息或“立即引导”使用新选择。已有回复保留，切换模型本身不会中断正在进行的请求。
- 本地会话统一列出，不再区分聊天和工作；已保存的工作空间文件仍长期保留，支持导出、保存回复和图片生成。图片生成使用当前模型调用 `/images/generations`，需要中转站及所选模型支持。
- Codex：SSH 连接官方 `codex app-server`，复用服务器原有账号、配置和历史。不安装第三方服务器程序，不开放额外公网端口。
- 远程服务器统一从顶部 Codex 菜单切换，菜单按各主机的真实连接显示状态圆点；已移除云端占位入口及侧栏底部重复主机列表。
- 侧栏按最近打开的本地会话排序，后台回复不改变顺序；每次展开从顶部开始，设置下方可新建对话。归档先确认，可勾选以后不再提示；取消不保存这一偏好。
- 本地和远端正文按 Unicode 字形逐字柔和显示，系统帧时钟控制约 16 ms 的节奏；网络整段到达及任务结束后仍按顺序补完，等待时显示三个点。淡入结束清除原生文字的临时透明度样式，避免段尾字残留。已保存的历史回复直接显示全文。上滑阅读或展开命令输出时暂停自动跟随。AI 的复制按钮只在整轮结束且正文显示完成后出现，复制整轮回复；用户提示词可单独复制。
- 打开 App 自动尝试连接已保存的 SSH 主机并同步索引；各主机独立保持连接，SSH 心跳及断线重试不依赖当前页面。指纹未确认、指纹变化或用户拒绝时不自动重试。
- 手机 Codex 项目、时间、优先级及活动列表位于主内页；“打开项目”可浏览或输入远程目录，也可通过官方 `fs/createDirectory` 新建文件夹（不递归创建父目录，不覆盖现有目录）。空项目独立保存，首次发送才创建服务器会话；空白新对话可点击中央目录切换项目，先选择已保存项目；需要其他目录时才进入文件夹浏览。打开对话后返回键回到该列表。本地与远程使用相同的全局侧栏，包含本地对话及连接、设置入口；服务器选择菜单名称靠左、真实状态圆点靠右，连接页共用各主机状态，任务内仍可查看真实用量；在线为绿点，连接中为动画，离线为红点。执行中的对话显示转圈，支持切换及多个对话同时执行。原有归档、审批、压缩、审查等能力继续由官方协议提供。
- 本地不再显示聊天/工作切换；会话开始后，左上角菜单按钮动画展开为标题胶囊。设置页直接列出已保存的 API 供应商；模型、推理及真实速度档位使用输入框按钮旁的原生锚定菜单，供应商选项直接展开在供应商行下方，包含新增入口。Fast 以闪电图标显示，直接 API 没有速度元数据时不提供虚构档位。停止按钮为实心方块。
- 空白聊天和旧的仅助手占位记录不显示在列表；草稿仍可恢复，已有记录不删除，有导入文件的工作空间保留。首条真实用户消息用于未命名会话标题。
- 远程连接中保留历史和可输入的草稿，连接成功前禁止发送及远端斜杠动作。顶部显示连接动画和状态，连接尚未建立时不提示登录；确认远端确实缺少认证时才显示登录操作。
- 新远程对话继承最近显式选择的模型、推理和速度，首次默认中等（支持时）；旧对话保留自身配置。全局默认保存在 Android SharedPreferences。直接 API 对话单独保存模型与强度，供应商后台刷新或设置保存不会换掉当前对话的模型；供应商默认写入串行化，快速选择不会被旧写入覆盖。
- 助手正文不加气泡；用时位于用户消息之后、活动内容之前，运行时从 0 秒计时，完成后可展开活动详情。展开的思考摘要、命令正文可轻点收起，长按仍可选择复制，滑动保持展开。正文下方提供可展开的已编辑文件、左侧复制和完成时间；本地 API 回复使用相同的时间格式。时间来自官方回合元数据或本机观察，不为缺少时间的旧历史编造值；文件修改按真实回合归属，不跨回合混合。
- 本地回复、后续消息和键盘调整默认跟随最新内容；手动上翻后停留。附件菜单分别提供文件和图片，已保存文件使用独立入口。图片进入两个协议的视觉输入，UTF-8 文本进入模型内容，PDF 使用 Responses 的 input_file；每条最多 4 个附件，每个最多 8 MB，文本最多 1 MB。
- 正常界面显示服务器备注，不展示 IP。发送失败保留消息、附件和重试；目录暂未索引新任务时保留当前任务及流式正文。已被实时确认替换的临时 ID 不再从旧缓存复活；恢复历史保留期间收到的实时更新，只合并一次。
- 本地 API 请求与远程实时状态按对话保存，切走后继续接收消息，停止只操作当前对话；同一个已恢复远程对话优先复用实时状态，避免重复 resume。流式 Markdown 在后台解析，已完成正文在测量前解析为完整排版，流式新增文字按帧平滑显示，缓存写入合并到每 200 ms，避免逐字写盘。
- 完整代码块和文本文件使用带边框的内容框：Markdown、HTML、SVG 支持源码/预览切换，JSON 支持原文/格式化切换，其他代码保留原文和复制。Markdown 源码和预览复用同一个文字控件，切换不会先变成空内容框；正文滑动交给对话列表，保留长按选择。普通 Markdown 回复继续直接排版，逐字淡入结束后重建完整静态布局，再展示复制和时间，防止原生文本绘制缓存留下局部结果。Markdown 媒体链接支持图片、GIF/SVG、视频、音频，PDF 提供翻页预览，其他文件保留保存或外部打开。HTML 使用无同源权限的沙箱 iframe，无原生桥接、不访问本机文件；脚本不能请求网络接口。远端工作目录文件通过原有 SSH 的 SFTP 读取，不新增服务器软件；预览最多 64 MB，超出大小、缺少 SFTP 或系统不支持的编解码器可能无法内嵌播放。

API 中转站编辑页支持一键拉取 `/models`，保留已有手动 ID；模型以列表显示，支持搜索和每页 10 个模型，允许新增、编辑、删除和选择默认模型。推理档位默认自动匹配，单个模型可编辑实际 ID 或恢复自动匹配；中文用于已知档位的显示名称，自定义 ID 原样发送。每行可独立测试，列表顶部可测试全部，底部保存按钮只保存；测试会先保存当前配置。设置页仅保留供应商选择、名称、模型摘要和编辑入口；模型拉取和反馈集中在编辑页。测试按当前 Chat Completions / Responses 类型逐个请求，限制为 64 输出 token、每个 20 秒超时，随时可停止；仅上游明确拒绝不支持 `max_completion_tokens` 时，对 Chat Completions 回退为 `max_tokens`。结果及检查时间随配置保存，修改地址、密钥或接口类型会清除旧结果。成功收到文本才标记通过，接受请求却无文本标记未验证；目录中出现某个模型不代表支持该文本接口。

标准 `/models` 缺少能力元数据时，客户端从自有公开端点 `https://codeb.baiyun.si/api/client/reasoning` 补齐，支持精确 ID、最长系列前缀和供应商主机例外。优先保留服务报告或手动设置；明确报告空档位时不补齐。新选择默认 medium，不支持 medium 的模型使用规则声明的有效默认值。未知模型的 low / medium / high 是可编辑兼容模板，不能证明任意网关支持。Fast 不从模型名猜测。目录只下载静态 JSON，每天成功更新一次；超时或无效数据保留缓存，首次离线用 App 内置副本，不依赖原 DSH 插件或远端新服务。协议原始值不翻译，界面档位本地化，`Max` / `Ultra` 保留英文。

Responses 原生压缩调用 `/responses/compact`，保留完整本地历史，只将服务返回的不透明压缩结果用于后续请求。Chat Completions 或不支持该端点的中转站不能假装支持原生压缩。远程 Codex 的上下文压缩仍由服务器官方 Codex 执行。

## 存储原理

| 数据 | 手机私有存储路径 | 手动清理缓存 |
| --- | --- | --- |
| SSH 索引、已加载历史及草稿 | `files/local-cache/remote/` | 删除 |
| 本地普通聊天 | `files/local-cache/chats/` | 删除 |
| 脱敏诊断日志 | `files/local-cache/diagnostics.jsonl` | 删除 |
| 工作会话 | `files/workspaces/<hash>/conversation.json` | 保留 |
| 工作文件 | `files/workspaces/<hash>/files/` | 保留 |
| API 设置及加密密钥 | `files/api-providers.json` | 保留 |
| SSH 设置及加密凭据 | 原有 ConnectionStore / Android Keystore | 保留 |
| 新远程对话模型、推理与速度默认 | Android SharedPreferences composer-defaults | 保留 |

缓存放在 `filesDir` 而不是会被系统自动回收的 `cacheDir`。不设应用配额、不按时间或大小自动驱逐。卸载应用或系统的“清除应用数据”仍会删除私有数据，重要工作文件可导出。

远程首次同步会话目录；只获取被打开线程的最新五轮，向上滚动再加载更早分页。缓存合并保留实际读过的历史。旧 Codex 不支持分页时，仅对打开的线程回退完整读取，不批量下载全部正文。

JSON 使用 Android AtomicFile 防止写一半损坏；主机和任务分开哈希命名。草稿及流式回复通过修订号避免旧写入覆盖新内容；清缓存递增代次，拒绝删除前排队的旧缓存写入。此版采用单进程文件锁和完整 JSON 重写，历史很大或并发写入显著时应升级到 SQLite 分页记录，不以删历史解决性能问题。

空间不足会报告错误，不静默删旧资料。普通聊天可以复制为工作会话；缓存原件保留至用户清理，工作副本独立保存。

## 活动线程与后台限制

`thread ... already has an active writer` 表示另一个 Codex 进程持有写入权。此时使用官方只读 `thread/read` 和 `thread/turns/list` 每四秒同步已落盘历史，保留缓存，并禁用发送。不会删锁、杀进程或抢占会话；独立 CLI 的实时事件、发送、停止及审批不能通过另起 app-server 保证接管。结束原会话后，可重新打开线程尝试正常恢复。

SSH 连接使用前台 dataSync 服务和断开通知，返回键将应用放后台，不销毁会话。Android 15 对后台 dataSync 服务有六小时/24 小时系统限制，超时后保存已有磁盘缓存并关闭连接；重开应用后重连。厂商省电、断网、进程终止仍可能断开，不能承诺无限后台运行，也不能保证 SSH 断开后手机启动的远端任务继续执行。

参考：[官方 app-server 协议](https://developers.openai.com/codex/app-server)、[Android 前台服务时限](https://developer.android.com/develop/background-work/services/fgs/timeout)。

## AI / 开发者调试 API

仅开发版提供，默认关闭，在设置中显式打开。只绑定手机 `127.0.0.1:18765`，所有端点要求随机 Bearer token。首次启用或进程重启会轮换 token，页面重建和重复启用保持现有监听；关闭后删除 token 文件。端口占用不导致应用崩溃。发布版不允许开启。

| GET 端点 | 内容 |
| --- | --- |
| `/health` | 存活状态、协议版本 |
| `/state` | 当前模式、主机/会话数量、发送状态、缓存字节、只读状态 |
| `/logs` | 最近约 64 KiB 的结构化日志事件 |

日志保留没有容量上限，64 KiB 仅是单次读取窗口。诊断不返回密钥、IP、消息原文或可能含密钥的异常 message；返回异常类型和调用栈。接口只读，无执行命令、修改设置或发送消息能力。

连接 USB 真机并开启调试 API 后，PowerShell 可以这样调用，不把 token 打印到终端：

```powershell
adb forward tcp:18765 tcp:18765
$token = (adb shell run-as com.codex.remote.dev.debug cat files/debug-api.token).Trim()
$headers = @{ Authorization = "Bearer $token" }
Invoke-RestMethod http://127.0.0.1:18765/health -Headers $headers
Invoke-RestMethod http://127.0.0.1:18765/state -Headers $headers
Invoke-RestMethod http://127.0.0.1:18765/logs -Headers $headers
Remove-Variable token, headers
adb forward --remove tcp:18765
```

不要把 token、SSH 私钥或完整 API 请求上传到公开问题单。接口没有公网监听，仍应在调试完成后关闭。

## 构建与检查

### 更新与反馈

设置中的关于、更新检查及推荐使用 `https://codeb.baiyun.si/api/client/config`；推理模板使用 `/api/client/reasoning`，不再从 GitHub 下载。启动、回到前台时同步配置（5 分钟缓存），打开设置或手动检查更新强制同步。云端模板修订号变化后同步模板，离线使用内置副本或缓存；超过一天未更新的推荐隐藏。

更新按包名与 versionCode 判断，发现新版本后在 APP 内提示一次。用户打开 APK 直链或网盘链接后自行下载、安装；没有后台系统通知或自动安装服务。推荐开关控制整个区域，关闭时公开接口不返回推荐内容。推理手动编辑填写实际 ID，每行一个，可自定义；发送请求时原样使用，中文仅为已知档位的显示名称。

APP 可自行编译安装。远程会话通过 SSH 直连服务器上的官方 Codex。

JDK 17 / Android SDK 35：

```text
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest
./gradlew :app:connectedDebugAndroidTest
```
